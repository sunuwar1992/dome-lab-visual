# Dome Lab Visual

This is a static web app and can be deployed on any static hosting platform.

## Quick deploy options

### GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` from this folder.
3. In repository settings, enable GitHub Pages from the main branch root.
4. Share the published URL.

### Netlify
1. Drag and drop this folder into Netlify Drop, or create a new site from a Git repository.
2. No build command is needed.
3. Share the generated URL.

### Vercel
1. Create a new project.
2. Upload this folder or import a Git repository containing it.
3. Framework preset: Other.
4. No build command is required.
